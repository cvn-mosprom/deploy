# Безопасность

Не публикуйте секреты и персональные данные в issues. Сообщайте об уязвимости через GitHub Private vulnerability reporting, если он включён, либо владельцу репозитория через согласованный приватный канал.

High/Critical и секреты блокируют выпуск. Исключение требует владельца, причины и даты истечения; общий обход сканеров запрещён. Dependabot проверяет зависимости еженедельно, плановый workflow повторно сканирует выпущенные образы.
