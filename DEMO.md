# Локальный прототип для жюри

Запуск из deploy: `bash scripts/demo.sh up`, затем `bash scripts/demo.sh seed`. Требуются Docker Desktop с Compose v2 и соседний checkout backend с инициализированным frontend submodule. `MOSPROM_BACKEND_DIR` позволяет указать другой путь. Повторный запуск сохраняет БД; `bash scripts/demo.sh stop` останавливает контейнеры без удаления данных; `status` показывает состояние, `logs` — последние записи. `start` использует уже собранные образы.

Адреса: игра http://localhost:8080/, лендинг http://localhost:8080/landing, CRM http://localhost:8080/hr. Для CRM подходит любой шестизначный код, например 123456. CRM явно работает на синтетических демонстрационных данных: C4/C5 ещё не реализованы сервером. Игра, обучение, команды, сохранение прогресса, рейтинг и заявки лендинга используют настоящий API/PostgreSQL. Медиа обслуживаются SeaweedFS. seed добавляет 40 вымышленных игроков.

Compose project `mosprom-demo` использует отдельные постоянные volumes. На хост опубликован только 127.0.0.1:8080; PostgreSQL, Redis, sim и SeaweedFS доступны внутри Docker-сети. Пароли автоматически генерируются в игнорируемом `.env.demo` с правами 0600. Приложение и миграции работают разными непривилегированными ролями PostgreSQL. Кнопки лендинга открывают локальную игру. Telegram token не нужен и не используется. DEV_AUTH=1 предназначен только для этого локального профиля. Публичный туннель не запускается.

Интегрированы frontend/main a24726c, frontend/landing/grid-system 9abf754 и backend/main 9511669. При разрешении конфликтов сохранены новый контракт заявок, региональный resolver, revision guard, PATCH/CORS, HR middleware и исправленные Python/Caddy runtime. EXTERNAL_MEDIA=1 включается backend Compose для SeaweedFS; standalone production web по умолчанию сохраняет статические медиа.

Проверено: готовность БД, миграций, Redis, sim и media; 50 тестов маршрутизации/HTTP-клиента/лендинга; svelte-check без ошибок и предупреждений; браузерный сценарий подтверждения возраста и intro с сохранением состояния, загрузка видео с HTTP 206, вход в демонстрационную CRM без ошибок JavaScript. Полный регрессионный CI после новых продуктовых изменений пока не выполнялся.
